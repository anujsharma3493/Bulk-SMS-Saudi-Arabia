# Bulk SMS Saudi Arabia

## Delivery Monitoring

Delivery monitoring helps businesses understand the status of outgoing messages.

A messaging platform may provide statuses such as:

| Status    | Meaning                          |
| --------- | -------------------------------- |
| Submitted | Message accepted for processing  |
| Delivered | Message successfully delivered   |
| Failed    | Message was not delivered        |
| Pending   | Message is still being processed |

Delivery information can help technical teams identify messaging problems and help marketing teams evaluate campaign activity.

* Keep authentication information secure

Security should be considered during both the integration and operational stages.
